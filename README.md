# Hello World Task

## Description
This project contains a simple `index.html` file that displays **"Hello World!"** on the screen when opened in a browser.

## Files
- `index.html` — Main HTML file that prints "Hello World!" on screen using a `<p>` tag.
- `Readme.md` — This file.

## How to Run
1. Download/clone this folder.
2. Open `index.html` in any web browser (double-click the file, or right-click → Open with → Browser).
3. You should see **"Hello World!"** displayed on the screen.

## Task
Create an `index.html` file, printing "Hello World!" on screen.
